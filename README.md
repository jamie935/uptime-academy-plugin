# Uptime Academy for Cursor

Personal learning for AI, work and life, grounded in Uptime teaching and short Hack recommendations.

## Setup

Install the Uptime Academy plugin in Cursor, enable its `uptime-academy` MCP server, and use Cursor's authentication control to sign in to Uptime. Complete sign-in in the browser; never paste a password, code or token into chat. If access fails, reconnect the server in Cursor. This package connects to Uptime's hosted learning service.

Try:

- “Uptime, help me get more from AI in my marketing work.”
- “What can I learn from Atomic Habits? Show me its Uptime Hack.”
- “Academy, help me give difficult feedback as a new manager.”

Academy offers educational coaching across the Uptime library. It does not execute website or coding work. Opening recommended Hacks may depend on your Uptime membership.

## Privacy and memory

Only the learning request and explicitly shared, non-sensitive learner facts should be sent to Uptime. The skill forbids automatically attaching workspace files, repository content, editor context or secrets. Cursor's own context and data settings remain under your control; this instruction is not a technical sandbox.

Academy can remember useful learning goals and preferences for the authenticated Uptime account. Say “show memory” to inspect saved facts or “clear memory” to clear them. Clearing Academy memory does not delete Cursor chat history. Do not share confidential employer material, credentials or sensitive personal information.

[Privacy policy](https://uptime.app/privacy-policy/) · [Terms](https://uptime.app/terms-and-conditions/) · [Support](https://help.uptime.app/)

## Recommendation display

Recommendations use Markdown with exact Uptime links and genuine covers returned by the library. Cursor may not render every remote image; title, link and reason remain the fallback. This package avoids the unsupported interactive Hack-card UI.
